## 产品概述
将现有登录界面按参考图重新设计，替换为企业化铁路设备管理登录页。页面采用左右分栏视觉：左侧展示红色铁路标识、系统名称和铁路编组站航拍图，右侧展示简洁的账号登录卡片。

## 核心功能
- 左侧区域使用浅蓝色背景、红色铁路 Logo、系统标题和副标题。
- 左侧中部展示用户提供的铁路编组站航拍大图，整体比例接近参考图。
- 左右区域之间使用弧形过渡，右侧为白色背景。
- 右侧居中展示登录卡片，卡片标题为“XX局车务设备智能管理系统”，左侧带绿色竖线。
- 登录卡片仅保留用户名、密码、图形验证码和蓝色圆角登录按钮。
- 图形验证码保留彩色字符效果，点击后可刷新。
- 登录页不再展示手机登录、扫码登录和顶部标签页。
- 页面保留原有登录校验、登录成功跳转和权限初始化逻辑。
- 桌面端优先还原参考图，窄屏下保证表单可用、图片不变形。

## 视觉预期
整体风格清爽、企业化、信息克制。左侧突出铁路行业属性和品牌识别，右侧登录区域简洁、稳重、操作明确。

## Tech Stack Selection
- 沿用现有项目技术栈：Vue 3、TypeScript、Vite、Element Plus、SCSS、Pinia、vue-i18n。
- 不新增 npm 依赖。
- 使用项目现有 Canvas 验证码组合式函数 `useCaptcha.ts`。
- 用户提供的图片素材复制到项目 `src/assets/` 后引用，不引用 CodeBuddy 临时历史路径。

## Implementation Approach
采用“布局重构 + 表单样式适配 + 资源本地化”的方式完成改版。`src/views/login/index.vue` 负责整体左右分栏、品牌区、图片区和登录卡片容器；`src/views/login/component/account.vue` 继续负责用户名、密码、验证码及登录逻辑，只调整表单样式以适配新卡片。

关键决策：
- 使用 SCSS 实现浅蓝背景、弧形分界和登录卡片，避免额外图片资源。
- 保留 `account.vue` 的 Canvas 验证码、空值校验和验证码校验，降低登录逻辑回归风险。
- 移除登录页对手机登录和扫码登录的渲染，但保留相关组件文件，避免影响后续扩展。
- 标题和副标题按截图固定展示，平台原有主题标题不再作为登录页主标题来源。
- 表单输入框使用 Element Plus 原生组件，保证可访问性和一致性。

## Performance and Reliability
- 页面只加载两张本地静态图片，无额外网络请求。
- 弧形背景使用 CSS 伪元素和圆角实现，不引入大尺寸遮罩图。
- Canvas 验证码仍只在挂载和点击刷新时绘制，保持原复杂度。
- 不改登录成功后的 token、Cookie、RBAC 和路由逻辑，控制改动范围。

## Implementation Notes
- 复制素材时建议命名为 `login-railway.png` 和 `login-logo-red.png`，便于后续维护。
- 不要用截图中的“版权所有”水印，因为那是参考图水印，不属于页面设计。
- 保留 `account.vue` 中 `onSignIn` 的验证码校验、Session token 写入和 `Cookies.set('userName', ...)`。
- 若新增固定中文文案，需要同步补充到三语登录页配置，避免语言切换后出现原始 key。
- 窄屏下建议将左右分栏切换为上下结构，左侧图片控制高度，右侧登录卡片保持居中。

## Architecture Design
- `index.vue`：登录页布局、素材引用、标题/副标题、登录卡片容器。
- `account.vue`：账号密码验证码表单和登录业务。
- `useCaptcha.ts`：图形验证码生成、Canvas 绘制和刷新。
- `i18n/pages/login/*`：登录页文案。

## Key Code Structures
无需新增复杂接口或类型。沿用现有 `useCaptcha()` 返回的 `canvasRef`、`captchaCode` 和 `refresh` 方法即可。

## Design Style
整体采用企业后台登录页风格，以浅蓝、白色、铁路红和科技蓝为主色。左侧强调行业属性和品牌识别，右侧保持简洁、稳定、专业的登录体验。

## Screen 1：登录页

1. **左侧品牌区**
   顶部放置红色铁路 Logo、系统名称“南宁局务行车设备管理系统”和一行小字副标题，形成清晰的品牌识别。

2. **左侧主视觉区**
   中部偏下展示铁路编组站航拍图，使用圆角或柔和边框，四周保留浅蓝留白，图片比例接近参考图。

3. **弧形分界区**
   左侧浅蓝区域与右侧白色区域之间使用自然弧线过渡，增强页面层次感，避免生硬切割。

4. **右侧登录卡片**
   白色卡片居中放置，宽度约 360px，左侧增加绿色竖线，卡片标题为“XX局车务设备智能管理系统”。

5. **表单与按钮区**
   用户名、密码、验证码输入框纵向排列，验证码位于输入框右侧；底部使用蓝色圆角登录按钮，按钮文字为“登 录”。

6. **响应式处理**
   桌面端保持左右约 55:45 分栏；窄屏下切换为上下结构，左侧仅保留品牌区和缩略图，右侧登录卡片保持完整可用。
