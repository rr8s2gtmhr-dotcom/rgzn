## 产品概述

修复因编辑器反复撤销导致中文界面异常的问题。当前菜单、标签页和浏览器标题显示为 `message.router.dataMaintain` 等原始 i18n key，而不是中文名称。

## 核心功能

- 查明异常原因：`src/i18n/lang/zh-cn.ts` 中的自定义翻译条目被撤销，文件回退到 Git 原始版本。
- 将简体中文语言包恢复到撤销前的状态，补回减速顶业务菜单和标签页名称。
- 确保路由、标签页和浏览器标题不再显示原始 i18n key。
- 不覆盖工作区中大量未提交的既有改动。
- 保留 `dataRelarder` 原本为空字符串的历史状态；若后续需要标题，可再单独填写。

## 技术栈

- 现有项目：Vue 3 + TypeScript + Vite + Element Plus + Pinia + vue-i18n
- 修改类型：i18n 语言包配置恢复，不涉及组件、样式或路由结构调整

## 实现方案

问题根因是 `src/i18n/lang/zh-cn.ts` 回退到 Git 原始内容。路由 `src/router/route.ts` 仍使用 `message.router.data*` 等 i18n key，当简体语言包缺少对应条目时，vue-i18n 会直接返回 key 本身，因此界面显示成 `message.router.xxx`。

处理方式是以仍保留自定义内容的 `src/i18n/lang/en.ts`、`src/i18n/lang/zh-tw.ts` 为参照，在 `src/i18n/lang/zh-cn.ts` 的 `router` 区块精准补回丢失的简体中文条目。只修改该文件，不执行 `git checkout`、`git reset` 或任何会覆盖用户未提交改动的操作。

### 需要恢复的翻译条目

- `data: '减速顶管理'`
- `dataRelarder: ''`
- `dataDetection: '巡检作业'`
- `dataMaintain: '减速顶维修'`
- `dataDeldata: '巡检小车'`
- `system: '系统管理'`
- `systemDept: '单位管理'`

## 实施注意事项

- `src/i18n/lang/zh-cn.ts` 当前仍保留 `upgrade` 配置块，这是该文件撤销前的一部分内容，不能照搬 `en.ts` / `zh-tw.ts` 对该块的删除改动。
- `dataRelarder` 历史值为空字符串，恢复后该页面标题仍可能显示为 `- vue-next-admin`，这是撤销前的原有状态，不属于本次故障。
- `src/utils/other.ts` 的标题拼接逻辑无需修改；翻译恢复后 `webTitle` 会自然取到中文名称。
- 修改后依靠 Vite 热更新即可生效；若页面仍显示旧内容，执行一次浏览器硬刷新。
- 验证重点：`/maintain` 页面应显示「减速顶维修」，左侧菜单应恢复业务名称，标签页和浏览器标题不应再出现 `message.router.*`。
